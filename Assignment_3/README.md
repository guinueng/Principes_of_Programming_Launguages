# CSE271 Principles of Programming Languages

## Setting Up

1. Clone this repository using the following command.

   ```bash
    git clone https://github.com/UNIST-LOFT/CSE271-2024-Fall.git
   ```

2. Install [Racket](https://racket-lang.org/download/).
3. [Optional] Install [Visual Studio Code](https://code.visualstudio.com/download). You can also use any other text editor of your choice.
4. [Optional] Install [Magic Racket extension for Visual Studio Code](https://marketplace.visualstudio.com/items?itemName=evzen-wybitul.magic-racket). This extension will be handy for running Racket code from Visual Studio Code.
